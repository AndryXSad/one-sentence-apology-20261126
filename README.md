A single sentence of apology an AI assistant owes the person it works for: funny and human at once, a real comic turn about a real failure, in a voice that sounds like someone who means it rather than a support macro. Built for make.fun's "The One-Sentence Apology Your Agent Owes You" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the one sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
